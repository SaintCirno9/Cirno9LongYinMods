LongYinAttrReinforceMod

作者：SaintCirno9

这个模组会让角色六维属性额外影响生命上限和内力上限。
如果你觉得原版六维对生存与续航的反馈不够明显，可以用它继续放大养成收益。

一、模组作用
1. 在游戏原版属性结算完成后，额外按六维补充生命上限和内力上限。
2. 六项属性可以分别配置：
   力道、灵巧、智力、意志、体质、经脉。
3. 只追加生命上限与内力上限收益，不直接改六维本身。
4. 兼容原版 `CountHeroData` 的重算流程，战斗结算、伤势结算后也会按当前结果重新补足额外上限。
5. 对通过角色生成流程创建的新角色，以及新开档主角，会同步当前生命和内力到对应上限，避免初始资源不满。

二、安装方法
1. 先确认游戏已经正确安装 MelonLoader。
2. 将本模组文件放入游戏目录下的 `Mods` 文件夹。
3. 启动一次游戏，模组会自动生成配置文件。

三、配置文件位置
`UserData\LongYinAttrReinforceMod\rules.json`

四、配置说明
配置文件使用中文键名，直接修改数字即可。

默认规则：
{
  "力道": { "Hp": 0.35, "Mana": 0.0 },
  "灵巧": { "Hp": 0.2,  "Mana": 0.0 },
  "智力": { "Hp": 0.0,  "Mana": 0.15 },
  "意志": { "Hp": 0.35, "Mana": 0.1 },
  "体质": { "Hp": 1.0,  "Mana": 0.0 },
  "经脉": { "Hp": 0.0,  "Mana": 0.4 }
}

字段含义：
1. `Hp`：该属性每 1 点额外提供多少生命上限。
2. `Mana`：该属性每 1 点额外提供多少内力上限。
3. 设置为 `0` 表示关闭该属性对应的额外加成。
4. 修改配置后，重启游戏生效。

五、适用场景
1. 想让六维成长更有体感。
2. 想自己调高血量流、内力流或均衡流收益。
3. 想让不同 build 的资源成长差异更明显。

六、注意事项
1. 本模组不会改装备、门派、buff、伤势等原版来源，只是在原版结果上额外增加生命上限与内力上限。
2. 如果和其他同样修改属性结算、血量上限、内力上限、角色生成结果的模组一起使用，可能出现叠加或冲突。
3. 首次启动后如果没有生成配置文件，请先确认 MelonLoader 是否正常加载本模组。

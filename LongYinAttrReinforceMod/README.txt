LongYinAttrReinforceMod

作者：SaintCirno9

这个模组会让角色六维属性额外影响生命上限和内力上限。
如果你觉得原版六维对血量、蓝量的影响不够明显，可以用这个模组自行调整成长收益。

一、模组效果
1. 在原版属性结算完成后，额外按六维补充生命上限和内力上限。
2. 支持分别调整力道、灵巧、智力、意志、体质、经脉的加成。
3. 重新结算属性时，会尽量保持角色当前血量和内力的比例，避免因为刷新属性导致血蓝显示异常。

二、安装方法
1. 先确认游戏已经正确安装 MelonLoader。
2. 将本模组文件放入游戏目录下的 Mods 文件夹。
3. 启动一次游戏后，模组会自动生成配置文件。

三、配置文件位置
UserData\LongYinAttrReinforceMod\rules.json

四、怎么改配置
配置文件会使用中文字段，直接改数字即可。

默认规则如下：
{
  "力道": { "Hp": 0.35, "Mana": 0.0 },
  "灵巧": { "Hp": 0.2,  "Mana": 0.0 },
  "智力": { "Hp": 0.0,  "Mana": 0.15 },
  "意志": { "Hp": 0.35, "Mana": 0.1 },
  "体质": { "Hp": 1.0,  "Mana": 0.0 },
  "经脉": { "Hp": 0.0,  "Mana": 0.4 }
}

说明：
1. `Hp` 表示该属性每 1 点额外提供多少生命上限。
2. `Mana` 表示该属性每 1 点额外提供多少内力上限。
3. 改成 `0` 就表示关闭该属性对应的额外加成。
4. 修改配置后，重启游戏即可生效。

五、适合哪些玩家
1. 想提高养成反馈，让六维成长更有体感的玩家。
2. 想自己决定不同属性收益权重的玩家。
3. 想做偏高血、偏高蓝或更均衡 build 的玩家。

六、注意事项
1. 本模组只额外调整生命上限和内力上限，不直接修改六维本身。
2. 如果和其他同样修改属性结算、血量上限、内力上限的模组一起使用，可能会出现叠加或冲突。
3. 首次启动后如果没有生成配置文件，请先确认 MelonLoader 是否正常加载模组。

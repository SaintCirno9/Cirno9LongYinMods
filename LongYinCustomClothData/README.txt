《龙胤立志传》服装数据自定义 Mod（LongYinCustomClothData）

【功能】
1. 直接拦截并注入游戏资源 `GameData/SkinDataBase`。
2. 当前版本只支持覆盖原版已有服装数据。
3. 首次读到原版服装表时，会自动导出一份 `Vanilla_SkinDataBase.csv` 供参考。

【安装】
1. 确保游戏已经安装 MelonLoader。
2. 将 `LongYinCustomClothData.dll` 放到游戏根目录的 `Mods` 文件夹。

【配置】
1. 第一次启动游戏后，Mod 会在游戏根目录生成 `UserData\LongYinCustomClothData\SkinDataBase.csv`。
2. 同目录还会生成 `UserData\LongYinCustomClothData\Vanilla_SkinDataBase.csv`。
3. 配置文件路径：
   `UserData\LongYinCustomClothData\SkinDataBase.csv`
4. 默认表头固定为：
   `id,名字,加成效果,DLC`
5. 四列说明如下：
   - `id`：服装 ID。当前版本只接受原版 `SkinDataBase` 里已经存在的 `id`；不存在的 `id` 会被忽略。
   - `名字`：服装名称。
   - `加成效果`：服装词条文本，例如 `伤害0.02`、`学识4`、`轻功2`。
   - `DLC`：所属 DLC，原版常见值为 `-1`、`0`。
6. 非法值处理：
   - 缺少表头时，Mod 会自动补回表头。
   - 文件不是标准 UTF-8 时，Mod 会先警告，再尝试按 GBK 容错读取。
   - 若缺少必要列，当前这次注入会跳过，游戏继续使用原版服装表。

【使用说明】
1. 修改原版服装时，直接保留原版 `id`，改同一行的其他列即可。
2. 当前版本不支持新增服装外观，因此不要写原版里不存在的新 `id`。
3. `加成效果` 支持同时写多条，使用分号 `;` 分隔，例如：
   `伤害0.02;速度0.02`
   `剑法2;轻功2;闪避0.02`
4. `加成效果` 会随衣服品级变化；配置里填写的是二级衣服对应的基准加成。
5. 每一条都必须写成“合法词条名 + 数值”的形式；如果词条名不存在，游戏会在日志里报错并忽略该条。
6. 保存 CSV 后，重新启动游戏即可生效。
7. 控制台日志会显示这次注入替换了多少条；如果配置里写了新增 `id`，也会明确提示这些 `id` 已被忽略。

【默认示例】

2. 其中包含：
   - 常服、锦袍、夜行衣、医袍、百衲衣等基础服装
   - `白马红妆`、`风起青萍` 两条 DLC 服装数据
3. 当前默认示例里，每件衣服都额外附带了一条 `生命上限200`，便于直接测试多词条效果。

【限制】
1. 当前版本只改服装数据表，不改角色 Spine 外观资源。
2. 因此当前版本不支持真正新增一套带新外观的服装。
3. 如果只是想做“旧衣服换名字、换加成”，当前版本已经够用。

《龙胤立志传》功法属性自定义 Mod (LongYinCustomKungfuSkill)

【安装说明】
1. 本 Mod 依赖于 MelonLoader 运行环境。请确保你的游戏已经安装了 MelonLoader。
2. 将本压缩包中的 `LongYinCustomKungfuSkill.dll` 文件解压并放入游戏根目录下的 `Mods` 文件夹中（路径示例：`LongYinLiZhiZhuan\Mods\LongYinCustomKungfuSkill.dll`）。

【使用说明】
1. 安装好 Mod 后，第一次启动游戏时，它会在游戏根目录自动建立 `UserData\LongYinCustomKungfuSkill` 文件夹。
2. 第一次启动后，Mod 会准备好多配置目录和导出开关配置文件：
   - `Vanilla_KungfuSkillData.csv`：这是游戏原版的功法数据大全，仅供参考，你在里面的修改不会生效。
   - `Data`：多配置目录。你可以在里面建立多个【能转换成数字】的子文件夹，例如 `000`、`100`、`200`、`300`。
   - `LongYinCustomKungfuSkill.cfg`：控制是否导出原版功法图标的配置文件，默认是关闭导出。
3. 如果首次启动时没有检测到任何功法配置，Mod 会自动生成一份示例配置到 `Data\000\KungfuSkillData.csv`，并同时创建 `Data\000\Icons` 目录，方便你直接开始测试。
4. 为了兼容旧版本，Mod 仍会读取根目录下已有的 `KungfuSkillData.csv` 和 `Icons`；但新版**不会再自动创建**这两个旧路径，建议改用 `Data\000\KungfuSkillData.csv` 和 `Data\000\Icons`。
5. 自动生成的示例配置里带有多条“太祖XXX”隐藏测试功法。由于这些隐藏测试功法不会正常刷出对应秘籍，所以就算你用修改器去检索秘籍物品，找不到也是正常现象。
6. 修改【原版功法】时：从 `Vanilla_KungfuSkillData.csv` 中找到你想改的功法，把那一整行完整复制到你正在使用的配置文件中，然后保持 `id` 不变，再修改其它字段。
   - 如果你还想替换这个原版功法的图标，也必须先把这条原版功法写进配置文件；**只有配置里实际存在的原版功法**，Mod 才会尝试读取对应 PNG 并覆盖原版图标。
7. 新增【自定义功法】时：可以直接在某个 `Data\数字目录\KungfuSkillData.csv` 末尾继续添加；若你还在用旧版目录结构，也仍可暂时放在根目录 `KungfuSkillData.csv` 中。
8. 关键规则：
   - Mod 完全认准 `id` 去寻找并替换功法。
   - 原版功法如果只是改属性，`id` 必须保持原样。
   - `Data` 下只会读取【目录名可转换成数字】的子目录，并按数字从小到大加载，例如 `000 -> 010 -> 100 -> 200`。
   - 若同一个 `id` 对应的是【原版功法覆盖】，则后加载的配置会覆盖先加载的配置。
   - 若同一个 `id` 对应的是【新增功法】，Mod 不会让它们互相覆盖；而是按加载顺序把它们在内存里重新编号后依次注入，**不会修改你原始文件里的 `id`**。
   - 因此，多份配置里的新增功法 `id` 可以重复，也不要求跨文件连续；最终游戏内实际使用的新增功法 `id` 会自动顺延分配。
9. `所属势力` 字段可填写的 ID 如下：
   - `0=长乐帮`，`1=唐门`，`2=药王谷`，`3=丐帮`，`4=飞龙门`，`5=茅山派`
   - `6=铸剑山庄`，`7=五毒教`，`8=阎罗殿`，`9=大隐阁`，`10=少林寺`，`11=武当派`
   - `12=霸刀门`，`13=蓬莱派`，`14=峨眉派`，`15=崆峒派`，`16=神机门`，`17=霹雳堂`
   - `18=金刚密宗`，`19=天山派`，`20=聚义门`，`21=黄河帮`，`22=八卦门`，`23=海沙帮`
   - `24=铁掌帮`，`25=仙霞派`，`26=巨鲸帮`，`27=金龙帮`，`28=青城派`，`29=伏牛派`
   - 常见补充：`-1` 为江湖武功。
10. 等级得在 `0-5` 之间，`5` 就是最高级的绝世功法。
11. 自定义图标用法：
   - 可以把 PNG 放在根目录 `UserData\LongYinCustomKungfuSkill\Icons` 中。
   - 也可以放在某个数据目录自己的 `Data\数字目录\Icons` 中。
   - 文件名必须和配置里写的功法 `id` 一致，例如：`10000.png`。
   - 这套规则同时适用于“配置里写明的原版功法”和“新增的自定义功法”。
   - 若某个功法来自 `Data\100`，Mod 会优先读取 `Data\100\Icons\10000.png`，找不到时再回退到根目录 `Icons\10000.png`。
   - 若没有对应 PNG，Mod 会自动从原版同类型功法里挑一个图标进行分配。
12. 原版图标导出用法：
   - 打开 `UserData\LongYinCustomKungfuSkill\LongYinCustomKungfuSkill.cfg`。
   - 将 `EnableExportVanillaIcons=false` 改为 `EnableExportVanillaIcons=true`。
   - 进入游戏并触发图标加载后，Mod 会把原版功法图标导出到 `UserData\LongYinCustomKungfuSkill\原版Icons`。
   - 这个功能默认关闭，仅用于调试或取原版图标素材。
13. 保存表格后再次启动游戏，你的新属性或新增功法就会在游戏中自动生效。
14. （可选验证）如果你想确认是否生效，可以查看 MelonLoader 控制台窗口：
   - 修改原版功法时，会输出字段变更日志。
   - 新增功法时，会按类型整块输出，并显示是“检测到自定义图标”还是“分配图标 ID=XXX”。
   - 如果 `id` 不连续，会明确提示缺失的 `id`，以及缺失点之后的功法未注入。

【字段格式速查】
1. 原版 `vanilla_KungfuSkillData.csv` 共 29 列，表头如下：
   - `id,类别,等级,名字,描述,基础威力,经验系数,修炼效果,运功效果,威力系数,修炼需求,攻击范围,伤害范围,使用特效,内力消耗,所属势力,使用目标,攻击架势,防御架势,召唤ID,使用次数,动作,子弹,特效,使用武器,伤害顺序,角色位移,Trail,隐藏`
2. 常用基础规则：
   - `id`：整数。
   - `类别`：只能是 `内功 / 轻功 / 绝技 / 拳掌 / 剑法 / 刀法 / 长兵 / 奇门 / 射术`。
   - `等级`：只能是 `0-5`。
   - `名字`：不能为空。
   - `经验系数`、`内力消耗`：必须是数字。
   - `基础威力`：可留空；不留空时必须是数字。
   - `所属势力`：建议填写 `-1` 或 `0-29`。
   - `使用目标`：目前按原版规则只接受 `0`、`1`、`4`。
   - `角色位移`：只能写 `TRUE` 或 `FALSE`。
   - `隐藏`：只能写 `0` 或 `1`。
   - `伤害顺序`：若填写，只能是 `Same`、`Distance`、`Random`。
   - `Trail`：整数；原版目前基本都是 `0`。
3. 复合字段规则：
   - `修炼效果`、`运功效果`、`威力系数`、`修炼需求`：多个条目之间用分号 `;` 分隔，例如 `内功1;经脉1`。
   - `攻击范围`、`伤害范围`：若填写，必须是 3 段整数，用逗号分隔；因为里面有逗号，所以 CSV 里通常要写成 `"1,1,1"` 这种带引号形式。
   - `攻击架势`、`防御架势`：通常写成 `部位+数值`，多个条目用分号分隔，例如 `手8;足8`。
   - `特效`：通常是资源名，多个条目用分号分隔。
   - `子弹`：这是专用参数字段，原版格式并不完全统一；建议优先照抄原版写法。
4. 按类别的经验规则：
   - `内功`、`轻功`、`绝技` 通常没有 `基础威力`、`攻击范围`、`动作` 这类直接攻击字段。
   - `拳掌`、`剑法`、`刀法`、`长兵`、`射术` 通常会填写战斗相关字段。
   - `奇门` 的格式最混合，既有偏攻击型写法，也有偏特殊效果型写法。
5. CSV 注意事项：
   - 含逗号的字段必须保留 CSV 引号。
   - 不要把 `角色位移` 的 `TRUE/FALSE` 和 `隐藏` 的 `0/1` 混着写。

【内置校验】
1. Mod 读取配置时，会对关键字段做基础合规校验。
2. 目前会检查这些字段：
   - `id`、`类别`、`等级`、`名字`
   - `基础威力`、`经验系数`、`内力消耗`
   - `所属势力`、`使用目标`
   - `攻击范围`、`伤害范围`
   - `召唤ID`、`使用次数`
   - `伤害顺序`、`角色位移`、`Trail`、`隐藏`
3. 如果某一行字段格式不合规，Mod 会在控制台输出警告，并**跳过整行**，不会让坏数据继续注入。
4. 额外的类别必填规则：
   - `拳掌 / 剑法 / 刀法 / 长兵 / 射术`：必须填写 `攻击范围`、`伤害范围`、`动作`、`伤害顺序`；通常也应填写 `基础威力`，但如果该技能设置了 `召唤ID`，则允许 `基础威力` 为空。
   - `奇门`：必须填写 `攻击范围`、`伤害范围`、`动作`、`伤害顺序`，但 `基础威力` 允许留空。
5. `基础威力` 目前允许填写负数，只要它本身是合法数字即可通过校验。
6. `特效`、`子弹`、`使用武器` 这类更偏资源名或专用脚本参数的字段，目前不会做过严校验，避免误伤自定义内容。


【注意事项】
1. **文件编码乱码预防**：使用老版本 Windows 的 Excel 直接保存 CSV 可能会导致编码被改写为 GBK 从而让 Mod 报错。如果你用 Excel 修改并保存了表格，请在此后右键该 CSV 文件 -> 选择“打开方式”为“记事本” -> 点击左上角“文件”-“另存为”，并在弹出窗口的右下角编码格式确认选择为 **带有 BOM 的 UTF-8**（或 UTF-8）后覆盖保存一次。
2. 建议玩家直接使用 **Notepad++** 或 **VS Code** 这类专业的文本编辑器来修改 CSV 表格里的数据，这样可以绝对避免因编码突变导致的系统崩溃。
3. 如果你已经生成过 `KungfuSkillData.csv`，后续升级 Mod 时不会自动覆盖你的旧配置；想使用新版示例时，请自行备份后再手动替换。

# Changelog

## 2.4.3

- 移除将小门派自定义功法额外加入江湖公共池的补丁，修复新游戏中仙霞派等门派的专属功法出现在其他小门派藏经阁的问题。
- 功法继续由游戏原生加载器按所属势力分池；只有所属势力为 `-1` 的功法进入江湖公共池。
- 为拍卖生成过程增加独立的自定义小门派功法候选池，可见的新增功法按原生抽到的功法等级参与随机，不修改江湖公共池或门派专属池。
- 保留原版拍卖物品数量、秘籍品质和大门派秘籍抽取分支；隐藏功法不参与拍卖，已有江湖功法不会重复加入候选池。
- 拍卖作用域在正常结束或异常时都会恢复，其他秘籍生成入口不受影响。

## 2.4.2

- 修复自定义功法加入江湖秘籍随机池时误写入 `0` 号长乐帮秘籍池的问题。

## 2.4.1

- 兼容新版游戏中 `GameDataController.kungfuSkillDataList` 改为字典结构，修复加载后注入江湖秘籍随机池时的 `MissingMethodException`。
- 自定义功法加入江湖秘籍随机池时会跳过不存在的稀有度池，避免异常中断后续加载。
